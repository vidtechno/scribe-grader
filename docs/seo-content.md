# SEO content map

Public pages are rendered on the server by `api/seo.ts`, `api/blog.ts` and the helpers in `api/_lib/`. Data lives in `api/_lib/data-*.ts`;
the `*-new.ts` / `-a.ts` / `-b.ts` files were added as later batches and are merged into the main arrays.

| Section | Data | Pages |
|---|---|---|
| Uzbek word lists `/inglizcha-sozlar/*` | `data-learn-words*.ts` | 30 |
| Uzbek grammar `/ingliz-tili-qoidalari/*` | `data-learn-guides*.ts` | 27 |
| Course lessons `/ingliz-tili-darslari/*` | `data-course.ts` (generated by `scripts/build-course-seo.ts`) | about 360 |
| IELTS Speaking Part 1 / 2 / 3 | `data-part1*.ts`, `data-part2*.ts`, `data-part3*.ts` | 42 / 65 / 28 |
| IELTS Writing Task 2 / Task 1 | `data-task2*.ts`, `data-task1.ts` | 50 / 12 |
| IELTS vocabulary | `data-vocab*.ts` | 12 |
| IELTS Reading and Listening practice, site map | `practice-pages.ts` | 3 |
| Blog | database `blog_posts` plus `data-blog-new.ts` (static guides merged in `posts.ts`) | 11 + 18 |

Rules: titles stay within about 60 characters (`fitTitle`), every page has one canonical URL, structured data (FAQ, Article, Breadcrumb) is generated
from the data, and `/sitemap.xml` lists everything. Static blog posts are not stored in the database, so they never trigger Telegram announcements.
